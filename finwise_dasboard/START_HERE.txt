FINWISE v1.3 — HONG KONG SHOPPING EDITION

This version does NOT need Gemini API / Google AI Studio.
Two free-tier API services replace it:
  - Tavily for live shopping web search
  - OpenRouter for free-model ranking/explanations

1. Extract the COMPLETE ZIP into a NEW project folder.
2. Preserve your old financial records by copying the old data/budget.sqlite3
   into the new project's data/ folder. Back up the file first.
3. Create two keys on your own accounts:
     OpenRouter: https://openrouter.ai/settings/keys
     Tavily:     https://app.tavily.com/
4. In the project folder on Mac/Linux:
     cp .env.example .env
     nano .env
   Insert both keys and keep model openrouter/free:
     OPENROUTER_API_KEY=YOUR_REAL_KEY
     TAVILY_API_KEY=YOUR_REAL_KEY
     OPENROUTER_MODEL=openrouter/free
   Save: Ctrl+O, Enter, Ctrl+X.
5. Start: python3 run_dashboard.py
6. Open http://127.0.0.1:8000 and use Can I afford it?

OFFLINE CLASSROOM DEMO WITHOUT KEYS:
  Set SHOPPING_DEMO=1 in .env, restart. All offers clearly marked fictional.

To seed fictional FINANCIAL transactions into an EMPTY database only:
  python3 run_dashboard.py --demo

Troubleshooting: SHOPPING_SETUP.md.

Note: Providers' free tiers and regional support can change. We could not
exercise a real key from a Hong Kong network in the automated tests.
